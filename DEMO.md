# Local demo script

1. Run the server as described in README and open http://127.0.0.1:8000.
2. Paste: `I am an Erasmus student in Romania. I need a residence permit, a learning agreement update and proof of health insurance.`
3. Select **Find my next steps**. Point out the three source-linked demo paraphrases: IGI studies [R1], Erasmus+ learning agreement [L1], and Student Charter [H1]. The date is when each source was checked, not when published.
4. Show the suggested dated checklist. Dates are planning suggestions, not deadlines. Confirm the applicable route and deadlines with IGI and both universities.
5. Show the blank draft fields from the linked IGI form. Optionally add a separate line `Study grade: 2` to the prompt and run again to see the value copied. Review the actual form and all values; nothing is submitted.
6. Try an unrelated question such as `Can I bring my cat?` to show the no-evidence response. Optional source text is displayed as unverified and is not used as official evidence.

Suggested narration: "CiteDesk brings a narrow set of official guidance together, tells you where it came from, and helps you prepare questions and fields for review. It does not decide your eligibility or submit forms."
